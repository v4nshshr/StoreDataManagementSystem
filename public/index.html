Category Sales & Profit Breakdown

Calculates total revenue and profit across product categories using $unwind, $lookup, and $group.

MongoDB Aggregation Query (Pipeline 1)
db.orders.aggregate([
  // 1. Unwind embedded order items array into individual documents
  { $unwind: "$items" },

  // 2. Lookup (Join) with products collection to fetch Category
  {
    $lookup: {
      from: "products",
      localField: "items.productId",
      foreignField: "productId",
      as: "product"
    }
  },
  { $unwind: "$product" },

  // 3. Group by Category and sum total sales & profit
  {
    $group: {
      _id: "$product.category",
      totalSales: { $sum: "$items.sales" },
      totalProfit: { $sum: "$items.profit" },
      itemCount: { $sum: 1 }
    }
  },

  // 4. Sort descending by highest sales
  { $sort: { totalSales: -1 } }
]);

Monthly Sales & Profit Timeline

Extracts year and month from order date fields using MongoDB date expressions $year and $month.

MongoDB Aggregation Query (Pipeline 2)
db.orders.aggregate([
  // 1. Group by Year and Month extracted from orderDate field
  {
    $group: {
      _id: {
        year: { $year: "$orderDate" },
        month: { $month: "$orderDate" }
      },
      totalSales: { $sum: "$totals.sales" },
      totalProfit: { $sum: "$totals.profit" },
      orderCount: { $sum: 1 }
    }
  },

  // 2. Project clean period string (YYYY-MM) and round numbers
  {
    $project: {
      _id: 0,
      period: {
        $concat: [
          { $toString: "$_id.year" },
          "-",
          { $cond: [{ $lt: ["$_id.month", 10] }, { $concat: ["0", { $toString: "$_id.month" }] }, { $toString: "$_id.month" }] }
        ]
      },
      totalSales: { $round: ["$totalSales", 2] },
      totalProfit: { $round: ["$totalProfit", 2] },
      orderCount: 1
    }
  },

  // 3. Chronological sorting
  { $sort: { period: 1 } }
]);

Shipping Transit Time Analysis

Average delivery transit days computed via date arithmetic in $project.

MongoDB Aggregation Query (Pipeline 4)
db.orders.aggregate([
  // 1. Subtract orderDate from shipDate (milliseconds to days)
  {
    $project: {
      shipMode: 1,
      shippingDays: {
        $divide: [{ $subtract: ["$shipDate", "$orderDate"] }, 86400000]
      }
    }
  },
  // 2. Calculate average days per ship mode
  {
    $group: {
      _id: "$shipMode",
      avgShippingDays: { $avg: "$shippingDays" },
      orderCount: { $sum: 1 }
    }
  },
  { $sort: { avgShippingDays: 1 } }
]);
